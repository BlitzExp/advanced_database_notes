## What I understood
- A table is created with columns, data types, and constraints like `PRIMARY KEY`.
- A trigger runs automatically when a database action happens.
- A `BEFORE INSERT` trigger can assign values before saving a new row.
- A `BEFORE UPDATE` trigger can check if the user is allowed to modify a row.
- A `BEFORE DELETE` trigger can prevent deletion unless the user has permission.
- `:NEW` is used for new row values, and `:OLD` is used for existing row values.
